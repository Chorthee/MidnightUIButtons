# Midnight UI Buttons

A lightweight World of Warcraft addon that adds a customizable tray for quick access to system commands and the Addon Manager.

## Features

* **Quick Access:** Dedicated buttons for Reload UI (`/reload`), Quit (`/quit`), and Logout (`/logout`).
* **Addon Manager:** A quick-toggle button for the in-game Addon List.
* **Modern Settings:** Fully integrated into the Blizzard Options menu (Esc > Options > Addons).
* **Fully Customizable:**
    * **Lock/Unlock:** Drag the tray anywhere on your screen and lock it in place.
    * **Scaling:** Adjustable UI scale from 50% to 200%.
    * **Typography:** Adjustable font sizes for button text (10pt to 30pt).
* **Sleek Aesthetic:** Designed with a dark "Midnight" theme to blend into minimalist UIs.

## Installation

1. Download the repository as a ZIP file.
2. Extract the `MidnightUIButtons` folder.
3. Move the folder to your World of Warcraft directory:
   `_retail_\Interface\AddOns\MidnightUIButtons`
4. Restart the game or type `/reload` if you are already logged in.

## Configuration

Open the main game menu (Esc), go to **Options**, select the **Addons** tab, and click on **Midnight UI Buttons**. 

From here you can:
* Toggle the movement lock.
* Use the **Button Scale** slider to resize the entire tray.
* Use the **Font Size** slider to change the text labels on the buttons.
